How to use it — two bookmarklets, two steps
Step 1 — On the UPS dashboard Create Shipment page:
1. Set weight and dimensions on the UPS order (toggle Simple Rate OFF)
2. Click 📋 Read UPS Order bookmarklet
3. Confirm the data it read — click OK
4. PeriShip Shipping Labels opens automatically

Step 2 — On PeriShip after clicking Create Label:
5. Click 🚀 Fill PeriShip bookmarklet
6. All recipient and package fields fill instantly from the UPS data
7. Select service type → buy label
